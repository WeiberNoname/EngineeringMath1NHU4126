
# Fourier Series Analysis: Power System Harmonic Analysis

Based on the problem description provided in the image, we need to expand the AC-side input current (a periodic square wave) generated by a single-phase fully-controlled bridge rectifier with an inductive load into a **Fourier Series** and analyze its AC-side harmonic characteristics.

---

## 1. Given Conditions

* **Period**: $T = 0.02\text{ s}$ (Grid frequency $50\text{ Hz}$)
* **Fundamental Angular Frequency**: $\omega = \frac{2\pi}{T} = 100\pi\text{ rad/s}$
* **DC Output Current**: $I_d = 100\text{ A}$
* **Current Waveform Function $i(t)$ within one period**:
  $$i(t) = \begin{cases} I_d, & 0 < t < \frac{T}{2} \\ -I_d, & \frac{T}{2} < t < T \end{cases}$$

---

## 2. Fourier Series Expansion Derivation

The general expression for the Fourier series of a periodic function $i(t)$ can be represented as:
$$i(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} [a_n \cos(n\omega t) + b_n \sin(n\omega t)]$$

### (1) DC Component $a_0$ and Cosine Coefficients $a_n$
Observing the waveform characteristics of the function $i(t)$, it is an **odd function**, satisfying $i(-t) = -i(t)$, and possesses **half-wave symmetry**, meaning $i(t + \frac{T}{2}) = -i(t)$.

Therefore, we can directly determine:
* DC component: $a_0 = 0$
* Cosine coefficients: $a_n = 0 \quad (\text{for all } n)$

### (2) Sine Coefficients $b_n$
Utilizing the properties of odd functions and half-wave symmetry, the sine coefficients $b_n$ only exist when **$n$ is an odd number ($n = 1, 3, 5, \dots$)**. The calculation formula simplifies to:
$$b_n = \frac{4}{T} \int_{0}^{\frac{T}{2}} i(t) \sin(n\omega t) \, dt$$

Substituting $i(t) = I_d$ into the equation:
$$b_n = \frac{4}{T} \int_{0}^{\frac{T}{2}} I_d \sin(n\omega t) \, dt = \frac{4I_d}{T} \left[ -\frac{1}{n\omega} \cos(n\omega t) \right]_{0}^{\frac{T}{2}}$$

Since $\omega = \frac{2\pi}{T}$, we have $\omega \cdot \frac{T}{2} = \pi$. Substituting the integration limits:
$$b_n = \frac{4I_d}{T} \cdot \frac{T}{2n\pi} [ -\cos(n\pi) + \cos(0) ] = \frac{2I_d}{n\pi} [1 - \cos(n\pi)]$$

* When $n$ is **even**, $\cos(n\pi) = 1 \implies b_n = 0$
* When $n$ is **odd**, $\cos(n\pi) = -1 \implies b_n = \frac{4I_d}{n\pi}$

---

## 3. Final Fourier Series Expression

Substituting the coefficients back into the series expansion (retaining only the odd terms $n = 1, 3, 5, \dots$):

$$i(t) = \sum_{n=1,3,5,\dots}^{\infty} \frac{4I_d}{n\pi} \sin(n\omega t)$$

Substituting the given values $I_d = 100\text{ A}$ and $\omega = 100\pi\text{ rad/s}$:

$$i(t) = \frac{400}{\pi} \sin(100\pi t) + \frac{400}{3\pi} \sin(300\pi t) + \frac{400}{5\pi} \sin(500\pi t) + \dots$$

---

## 4. AC-Side Harmonic Characteristics Analysis

Based on the Fourier series expansion results, we can summarize the harmonic characteristics of the AC-side input current as follows:

1. **No DC Component and Even Harmonics**:
   Because the waveform features ideal half-wave symmetry, the current contains no DC component ($a_0=0$) and completely lacks even harmonics ($2^{\text{nd}}, 4^{\text{th}}, 6^{\text{th}}, \dots$).
2. **Contains Only Odd Harmonics**:
   The input current is entirely composed of the fundamental frequency ($n=1$) and odd harmonics ($3^{\text{rd}}, 5^{\text{th}}, 7^{\text{th}}, \dots$).
3. **Harmonic Amplitude is Inversely Proportional to Harmonic Order**:
   The peak amplitude of the $n^{\text{th}}$ harmonic is $I_{nm} = \frac{4I_d}{n\pi}$. As the harmonic order $n$ increases, the amplitude decays rapidly.
4. **RMS Values of Harmonics**:
   $$I_n = \frac{I_{nm}}{\sqrt{2}} = \frac{4I_d}{\sqrt{2}n\pi} = \frac{2\sqrt{2}I_d}{n\pi} \approx \frac{0.9}{n} I_d$$
   * **Fundamental RMS ($n=1$)**: $I_1 \approx 0.9 \times 100\text{ A} = 90\text{ A}$
   * **$3^{\text{rd}}$ Harmonic RMS ($n=3$)**: $I_3 \approx 30\text{ A}$
   * **$5^{\text{th}}$ Harmonic RMS ($n=5$)**: $I_5 \approx 18\text{ A}$
